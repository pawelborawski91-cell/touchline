# touchline

TOUCHLINE is a mobile-first, landscape-only 11v11 tactical football game for iOS and Android.
Both sides plan at the same time, then the plans play out in continuous simulation on a 2D
105 × 68 m pitch. The match engine is plain TypeScript and does not depend on the mobile UI.
Rendering uses React Native Skia.

**Status: Sprint 1, the pitch renderer.** The app opens a landscape match view: a 105 × 68 m Skia
pitch with both 4-3-3 line-ups (NORTH CITY vs SOUTH UNITED) and the ball, under a touch camera.
There is no simulation or gameplay yet; score and clock are static placeholders.

Camera gestures on the match view:

- **Drag** with one finger to pan (with momentum).
- **Pinch** to zoom about your fingers; move them while pinching to pan as well.
- **Double-tap** to zoom in on that spot; double-tap again to return to the full pitch.

## Prerequisites

- Node.js ≥ 20.19.4 (developed on Node 22)
- pnpm 10 (`corepack enable` picks up the version pinned in `package.json`)
- For device builds:
  - **iOS:** macOS with Xcode and an iOS Simulator, plus CocoaPods
  - **Android:** Android Studio with an SDK, an emulator or a USB-debuggable device, and JDK 17

## Setup

## Everyday commands (run from the repo root)

| Command          | What it does                                                |
| ---------------- | ----------------------------------------------------------- |
| `pnpm dev`       | Start the Expo dev server (Metro) for the development build |
| `pnpm ios`       | Build and launch the iOS development build (`expo run:ios`) |
| `pnpm android`   | Build and launch the Android development build              |
| `pnpm typecheck` | `tsc --noEmit` in every workspace package and in `tests/`   |
| `pnpm test`      | Run Vitest once (`pnpm test:watch` for watch mode)          |
| `pnpm lint`      | ESLint, including package-boundary import rules             |
| `pnpm format`    | Format with Prettier (`pnpm format:check` to verify only)   |
| `pnpm validate`  | typecheck + test + lint + format check                      |

## Running the app

TOUCHLINE uses native modules (Skia, Reanimated, Gesture Handler, SQLite), so it needs an
**Expo development build** (`expo-dev-client`). Expo Go is not a supported target. Native `ios/` and
`android/` folders are generated by `expo prebuild`, are git-ignored, and should not be edited by
hand. Configure native behaviour in `apps/mobile/app.json` instead.

### iOS (macOS)

```bash
pnpm install
pnpm ios            # first run: prebuild + pod install + Xcode build, then launches the simulator
# later sessions, once the dev build is installed:
pnpm dev            # then press "i" or open the TOUCHLINE app on the simulator
```

To use a physical device, run `pnpm --filter @touchline/mobile exec expo run:ios --device`.

### Android

```bash
pnpm install
pnpm android        # first run: prebuild + Gradle build, installs on the running emulator/device
# later sessions:
pnpm dev            # then press "a" or open the TOUCHLINE app
```

### Cloud builds (no local Xcode or Android Studio)

```bash
cd apps/mobile
npx eas-cli@latest build:configure
npx eas-cli@latest build --profile development --platform ios   # or android
```
